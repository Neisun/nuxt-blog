就是这么个简单的需求。看一下结构和样式。
```html
<div class="container">
    <ul class="tab clearfix">
        <li class="tab-item active">新闻</li>
        <li class="tab-item">历史</li>
        <li class="tab-item">时尚</li>
    </ul>
    <!--内容部分直接投机取巧了，content就是内容区的容器，每一项内容宽高和容器保持一致-->
    <!--然后给容器overflow:hidden，能省就省的原则，是我的作风。。。  -->
    <ul class="content">
        <li class="content-item">新闻的内容</li>
        <li class="content-item">历史的内容</li>
        <li class="content-item">时尚的内容</li>
    </ul>
</div>
```

简单说一下js实现思路，点击当前的选项，然后当前选项处于激活高亮状态，然后使对应下标的内容区内容显示。
看一下jq。
```javascript
$(".tab-item").click(function () {
    $(this).addClass("active")
    .siblings().removeClass("active");
    // 最值得说道的就是获取当前的index这一句，别的都是小儿科。
    var index = $(".tab li").index($(this));
    console.log(index)
    $(".content-item").eq(index).show().siblings().hide();
})
```

重点说原生，原生玩的6，其他的真的就是浮云。
```javascript
var otabList = document.getElementsByClassName("tab-item");
var oContentList = document.getElementsByClassName("content-item");
for (var i = 0; i < otabList.length; i++) {
    // 存下标，一扩充对象的方式来存下标
    otabList[i].index = i;
    otabList[i].onclick = function () {
        console.log(this.index)
        for (var j = 0; j < otabList.length; j++) {
            // 使用原生的方式去掉类名
            otabList[j].classList.remove("active");
        }
        // 使用原生的方式添加类名
        this.classList.add("active");
        for (var j = 0; j < oContentList.length; j++) {
            // 如果样式并不是直接写在html的style中，你需要用这种方式来添加样式
            // element.style.cssText = "..."
            // 表问你是怎么知道，我最烦这句话，不是别人知道的多，是自己知道的太少
            oContentList[j].style.cssText = "display:none";
            oContentList[this.index].style.cssText = "display:block";
        }
    }
}
```
