在页面经常见到的一种效果，就是输入框在获取焦点的时候，底部会有一个横线从中间向两边缓缓展开，当失去焦点时候，这条横线又会从两边向中间缓缓收起，最后消失不见。
这种效果，看起来比较有趣。看看效果图

![](http://www.hunaisong.cn/wp-content/uploads/2017/10/focus.gif)

写法，我分为两种，一种是直接用css方式书写，另一种是辅以js。
css的写法呢，就是利用css3的transform中的scale，起初让横线的scale是0，当获取焦点的时候，就让scale变为1，然后给一个过渡时间。

**css写法**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>输入框底部效果</title>
    <style>
        *{
            margin: 0;
            padding: 0;
        }
        #myForm {
            margin: 50px auto;
            padding: 20px 10px;
            width: 300px;
            height: auto;
            background: #ccc;
        }
        .row {
            width: 100%;
            height: auto;
            position: relative;
            margin-bottom: 10px;
        }
        .field {
            width: 100%;
            outline: none;
            border: 2px solid transparent;
            height: 20px;
            box-sizing: border-box;
        }
        .bottom-line {
            position: absolute;
            top: 24px;
            left: 0;
            width: 100%;
            height: 2px;
            background: lime;
            transform: scale(0);
            transition: all linear 0.4s;
        }
        .field:focus+.bottom-line {
            transform: scale(1);
        }
    </style>
</head>
<body>
    <!-- 一个常见的动态交互效果，直接用css的写法，还有一种写法使用js写 -->
    <form id="myForm">
        <div class="row">
            <input type="text" name="name" value="" id="name" class="field">
            <span class="bottom-line"></span>
        </div>
        <div class="row">
            <input type="text" name="password" value="" id="password" class="field">
            <span class="bottom-line"></span>
        </div>
    </form>
</body>
</html>
```

js写法，相对于css的写法，js写法略显复杂，而且有点杀鸡用宰牛刀的意思。主要是学习实现的思路。
思路：首先是给`span`元素绝对定位，让它在中间老老实实待着，并且设置其`with`等于0，然后当`input`获取焦点的时候呢，我们就可以让这个`span`元素的`width`变为100%，然后left值变为0；

看一下实现的代码，用的jq，懒

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>输入框获取焦点底部效果js版</title>
    <script src="../js/lib/jquery-3.2.1.min.js"></script>
    <style>
        * {
            margin: 0;
            padding: 0;
        }

        #myForm {
            margin: 50px auto;
            padding: 20px 10px;
            width: 300px;
            height: auto;
            background: #ccc;
        }

        .row {
            width: 100%;
            height: auto;
            position: relative;
            margin-bottom: 10px;
        }

        .field {
            width: 100%;
            outline: none;
            border: 2px solid transparent;
            height: 20px;
            box-sizing: border-box;
        }

        .bottom-line {
            position: absolute;
            top: 24px;
            left: 50%;
            width: 0%;
            height: 2px;
            background: lime;
        }
    </style>
</head>
<body>
    <!-- 这是输入框获取焦点底部效果的js版本 -->
    <!-- 说一下思路，绝对定位之后，当获取焦点的时候让底部的span标签宽度达到100%，同时让left值变化，这就是最基本的思路 -->
    <form id="myForm">
        <div class="row">
            <input type="text" name="name" value="" id="name" class="field">
            <span class="bottom-line"></span>
        </div>
        <div class="row">
            <input type="text" name="password" value="" id="password" class="field">
            <span class="bottom-line"></span>
        </div>
    </form>
    <script>
        $(function($) {
            $('.field').focus(function() {
                $(this).next().animate({
                    'width': 100 + '%',
                    'left': 0
                }, 500)
            }).blur(function () {
                $(this).next().animate({
                    'width':0,
                    'left':50+'%'
                },500)
            })
        })
    </script>
</body>
</html>
```
