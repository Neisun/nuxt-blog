> 动手封装自己的函数库，需要的一些基础
废话不多说，谈一下为什么要自己封装函数。很简单，因为需求。许多时候，需求是促进能力和想象力提升的催化剂。虽然催化的作用小，因为需求的更改基本都是繁琐和琐碎的。但有时候，因为引用的函数库满足不了我们页面交互功能，这就需要我们自己动手封一个了。开始封印吧。。

![](http://hunaisong.cn/wp-content/uploads/2017/07/feng.jpeg)

> 封装的是一个自定义事件

浏览器的事件都是事先定义好的，我们定义的事件不属于浏览器事件，所以是一个自定义事件。
我们来看看代码，然后再看看如何调用,详细的部分，关于思路写在代码中了，边看边想边思考。
```javascript        
// 先来一个构造函数
function EventTarget() {
    // handlers是一个存放事件处理程序的对象
    this.handlers = {}
}
// 使用原型方式
EventTarget.prototype = {
    constructor: EventTarget,
    // 添加事件程序,type表示添加的事件处理程序类型，类似于click等等，handler是事件处理程序
    addHandler: function (type, handler) {
        // 提前判断是否存在handlers对象中到底存不存在这个type
        if (typeof this.handlers[type] === "undefined") {
            // 若不存在，就让其等于一个空数组，为什么是等于一个空数组，
            // 因为你的这一个type对应的事件可能有很多，难道一个click就对应一个事件？？
            // 这么想是不是就好多了
            this.handlers[type] = []
        }
        // 把handler也就是事件push到这个数组中
        this.handlers[type].push(handler)
    },
    // 触发事件,传入事件对象event，直接简写了e，
    // 因为是一个对象，所以在触发函数的时候，也就是调用函数时候，我们传入{type:"..",message:"..."}
    trigger: function (e) {
        // 在这打印出，看看，e到底是个什么东西，和浏览器的event对象有什么区别。
        console.log(e);
        // 判断e.target存不存在，不存在咋整？等于this，也就是EventTarget
        if (!e.target) {
            e.target = this;
        }
        // 对应的事件是一个数组，所以需要遍历来触发
        var handlers = this.handlers[e.type];
        for (var i = 0, len = handlers.length; i &lt; len; i++) {
            handlers[i](e);
        }
    },
    // 移出事件程序
    removeHandler: function (type, handler) {
        // 判断这个是否是数组
        if (this.handlers[type] instanceof Array) {
            var handlers = this.handlers[type];
            for (var i = 0, len = handlers.length; i &lt; len; i++) {
                if (handlers[i] === handler) {
                    // break i停止增加，因为for循环遍历停止。
                    // 此时i就是我们想要的，不用担心i变量的引用问题
                    break;
                }
            }
            handlers.splice(i, 1);
        }
    }
}
```
> 自定义事件写好了，看看怎么调用
```javascript        
// 在HTML中写一个简单的按钮就好，方便做一个测试。
// 获取按钮节点
var oBtn = document.getElementById("btn");
// new一个EventTarget，来获取其方法和引用
var target = new EventTarget();
target.addHandler("say", sayHello);
// 点击按钮，然后在点击事件中触发函数
oBtn.onclick = function (e) {
    target.trigger({
        "type": "say",
        "name": "Neisun"
    });
}
// sayHello 这个函数
function sayHello(e) {
    alert(" Hello, " + e.name);
}
```
