多人协同开发时候，容易出现的问题是作用域污染。说白了，就是变量名称冲突，导致功能出现问题，而且这种问题非常不容易调试，很难通过调试工具找出来。
那么，在开发的过程中能不能避免变量冲突。
我们可以利用函数的特性来实现。在`JavaScript`中，没有类的概念，没有块级作用域的概念。但是我们知道，在函数中定义的变量就是独属于这个函数，别人无法访问。利用这个特性，我们就可以做点文章。
一个自执行的函数，可以解决这个问题。
```javascript
        // 定义的是局部变量与函数，外层无法访问到
        // 本身js的function就是一个局部函数，拥有局部作用域；
        (function () {
            var length = 0;
            function init() {
                console.log('初始化')
                console.log('长度是：'+length)
            }
            function action() {
                console.log('功能模块函数')
            }
            init();
        })()
```
更高级一点的用法，如果我想让这个模块中有一个功能大家都可以用，也就是公共接口。怎么做？
```javascript
        // 另一种方式，定义的局部变量和函数有的是给全局使用的，需要暴露出去接口
        // 这种方式灵活，不想暴露出去的就是局部变量，不会被污染，而想暴露出去的，你就直接把他暴露出去;
        var myCurrentAction = (function () {
            var age = 0;
            function init() {
                console.log('初始化')
            }
            function action() {
                console.log('全局接口')
            }
            return {
                action:action
            }
        })()
        myCurrentAction.action()
```
再来点更新鲜的东西，如果一个模块想访问另一个模块的方法和属性。
```javascript
        // module1模块
        var module1 = (function () {
            var length = 1;
            var add = function () {
                ++length;
            }
            var minus = function () {
                --length;
            }
            // 在这里把想暴露出去的接口，暴露出去
            return {
                add:add,
                minus:minus,
                length:length
            }
        })()
        // module2模块，把module1以形参的方式传递进去，与module1存在依赖关系
        var module2 = (function (module1) {
            console.log(module1)
            var multiply = function () {
                // 调用module1的length
                return module1.length *= 2;
            }
            return {
                multiply:multiply
            }
        })(module1)
        // console.log(module2.multiply())
```
这种写法，适合于业务量小，不复杂的写法。如果业务量大，复杂的话。还是老老实实的   **`require.js`** ，这个才是真正意义上的模块化开发，有空的话，会仔细深入了解一下，同样，还有 **`sea.js`**
