> **手撸一个最常见的表单验证**

随处可见的UI框架层出不穷，每一个框架都有一套自己的表单验证体系。但并不是都会满足自己的需求，所以不如动手自己手撸一个表单验证。正所谓体系不行，那就打破体系，自立为体系。首先一个表单要有自己的样式，input域的focus样式，button的hover，focus样式，错误提示样式。
如果你有一个产品经理，你有一个UI，那这些你都不用操心，每种颜色都会提前给你设定好。但是，我们要手撸，所以需要提前考虑好这些问题，在着手做事情之前，你考虑的越全面，那么返工的麻烦就会越少。如果需要提前定义这些颜色，像js那样定义变量可以么。
答案永远是可以！没有什么不可能的，那么我就使用预编译语言就好。我偏向于less，因为语法简洁，可读性好。

如下，就是，我们定义基础和常用的功能样式；
```less
// 基本颜色
@bgColor:#f3f3f3;
@borderColor:#ccc;
@borderFocusColor:skyblue;
@errorColor:red;
@successColor:lightgreen;
@fontColor:#000;

// 字体相关
@fontSize:12px;
@fontWeight:400;
@fontFamily:'Arial","Microsoft YaHei","黑体","宋体",sans-serif';

// 默认按钮样式
.btn () {
    display: inline-block;
    padding: 0.5em 1em;
    // 不清除outline太丑
    outline: 0;
    // 给一个border，替代outline
    border: 1px solid transparent;
    color: #fff;
    text-align: center;
    white-space: nowrap;
    line-height: 1.2;
    cursor: pointer;
    transition: background 0.3s ease;

    user-select: none;
}

// 基础按钮样式
.btn-primary () {
    border-color: #0e90d2;
    background: #0e90d2;
    &:hover,&:focus {
        background: #0c79b1;
    }
    &::focus {
        outline: 1px auto -webkit-focus-ring-color;
        outline-offset: -2px;
    }
}

// formtips 错误提示基础样式
.formtips () {
    margin-left: 20%;
    width: 80%;
    font-weight: @fontWeight;
    font-size: @fontSize;
}
```

    margin: 0;
    padding: 0;

html,body {
    font-weight: @fontWeight;
    font-size: @fontSize;
    font-family: @fontFamily;

// 表单相关

    box-sizing: border-box;
    margin: 30px auto;

    width: 300px;
    height: auto;

    background: @bgColor;
    // 表单行

        margin: 0 0 10px 0;

        //所以采用这个hack解决
        font-size: 0;
        // label

            display: inline-block;
            width: 20%;
            height: 26px;
            text-align: right;
            font-size: @fontSize;
        }
        // input域
        .field {
            display: inline-block;
            box-sizing: border-box;
            padding: 3px 0 3px 5px;
            width: 80%;
            height: 26px;
            border: 1px solid @borderColor;
            border-radius: 3px;
            font-size: @fontSize;
            &:focus{
                outline: 0;
                border: 1px solid @borderFocusColor;
                box-shadow: 0 0 3px @borderFocusColor;
            }
            &.error {
                border-color: @errorColor;
                box-shadow: 0 0 3px @errorColor;
            }
            &.success {
                border-color: @successColor;
                box-shadow: 0 0 3px @successColor;
            }
        }
        // 错误提示
        .formtips {
            .formtips;
            &.wrong {
                color: @errorColor;
            }
        }
    }
    // 提交行
    .submit {
        margin-left: 20%;
        width: 80%;
        .btn {
            .btn;
            .btn-primary;
        }
    }
}

js部分直接使用jq来写了，要论操作DOM ，jq是祖宗级别的，不用它你用谁。
```javascript
// blur事件
$("form :input.required").blur(function (e) {
    // 获取到当前input的父级，也就是formgroup，方便后续操作
    var $parent = $(this).parent();
    // 获取当前input的value，方便后续操作
    var $val = $(this).val();
    // 在每次blur之前都需要把提示给删掉，不然会叠加，重复append；
    $parent.find(".formtips").remove();
    // 判断检测的类型，username？password
    if ($(this).is("#username")) {
        if ($val == "" || $val.length < 6) {
            var errorMsg = "输入至少6位用户名";
            $parent.append("<div class='formtips wrong'>" + errorMsg + "</div>");
            // 给当前input添加error样式，并移出success样式
            $(this).removeClass("success").addClass("error");
        } else {
            $(this).removeClass("error").addClass("success");
        }
    }
    if ($(this).is("#password")) {
        if ($val == "" || $val.length < 6) {
            var errorMsg = "输入至少6位密码";
            $parent.append("<div class='formtips wrong'>" + errorMsg + "</div>");
            $(this).removeClass("success").addClass("error");
        } else {
            $(this).removeClass("error").addClass("success");
        }
    }
})
// 为了给用户好的体验，让其在keyup时候就会验证，体现在代码上就是，在keyup时候就触发blur事件
.keyup(function (e) {
    // trigger，触发blur事件，这里使用triggerHandler，会触发你定义的blur事件
    // 区别于trigger
    $(this).triggerHandler("blur");
})
// 为了阻止用户恶意提交，在提交的时候，触发blur事件，做一个检测
$("#submit_btn").click(function (e) {
    $("form :input.required").trigger("blur");
    var $formtipsNum = $(".formtips").length;
    if ($formtipsNum > 0) {
        return false;
    } else {
        alert("表单已经提交！")
    }
})
```
