>写一个对象

我们平常写对象最常用的两种形式

```js
var obj = new Object();
obj.name = '...'
obj.age = '...'
```
又或者是

```js
var obj = {
    name:'...',
    age:'...'
}
```
而且，我们更倾向于选择，第二种方式，代码量更少，也更直观。二者基本上没有什么区别。

>数据属性

上边我们定义了obj对象，设置了属性和属性值。并且可以通过`obj.name`或者`obj[name]`访问。实际上，定义一个对象的属性，经历了这样一个小小的过程。

```js
var obj = {};
Object.defineProperty(obj,'name',{
    value:'...', // 属性的初始值
    writable:true, // 属性是否可写
    enumerable:true, // 属性可否被枚举
    configurable:true // 属性可否配置
})
```
上述代码中，展示了我们创建对象过程得机制。四种数据属性。

>访问器属性

getter与setter。之前我写过一篇文章关于setter和getter的，当时没有考虑好，没有把那个知识点系统划分。在我们创建一个对象的属性时候，实际上js有一种机制，让我们可以更改和访问属性。

我们通过一个例子，来看看使用方法。

```js
// year表示app的年份
// version表示出版的版本
// 随着年份的递增，版本号会递增，比如2018年，version应该是2
var obj = {
    year:2017,
    version:1
}
Object.defineProperty(obj,'_year',{
    get:function () {
        return this.year;
    },
    set:function (newValue) {
        this.year = newValue;
        this.version += newValue - 2017;
    }
    obj._year = 2020;
    console.log(obj.year,obj.version);
    // 2020,4
})
```
`_year`这个属性我们把它当做一个媒介，没有设置可枚举，所以在对象中看不到。
- 设置了get函数，所以我们可以通过`obj._year`获取
- 设置了set函数，所以我们可以设置，并且反映到year这个属性中，同时，设置version的值。
