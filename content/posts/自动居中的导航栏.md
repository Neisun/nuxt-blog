> **一切为了用户**

众所周知，前端所做的一切交互都是为了一件事情，为了用户的良好体验。那么在移动端我们经常会看到横向滚动的滚动条，这种设计为了节省空间，并且在点击某个选项式，该选项会自动居中，来提示用户当前的选择，这种效果非常常见也很实用。
最近在写移动端时候遇到这个问题，起初没有思路，后来借鉴了一下朋友的方法，在他的思路之上完善了一下自己的思路。
上一张图，看看他的手机站效果，顺便帮他公司打打广告。

> **实现的思路**

草绘完了，我们说一下思路。
当前点击项是视口中的第二个选项，想让他居中，那就需要让滚动条拉回一个导航栏的距离。
变成公式方式计算

屏幕的滚动距离：screenScroll(也就是容器元素的滚动条距离,scrollLeft)

当前元素的距离父容器的距离:offsetLeft，

当前视口的宽度：clientWidth

当前元素的宽度：width

最终：让滚动条移动到这个位置：screenScroll+(offsetLeft-clientWidth/2)+width/2;

```javascript
//js部分直接用jq写了
$(function() {
    $(".item").click(function() {
        $(this).addClass("active")
            .siblings().removeClass("active");
        var screenScroll = $("#app").scrollLeft();
        var distance = $(this).offset().left;
        var clientWidth = $("#app").innerWidth();
        var width = $(this).outerWidth();
        var leftX = distance - clientWidth / 2;
        $("#app").scrollLeft(screenScroll + leftX + width / 2);
    })
})
```
