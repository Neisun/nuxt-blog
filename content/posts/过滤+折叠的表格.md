> **无处不在的表格**

表格是页面中经常能见到的，也是最长用于展示页面信息的元素。那么折叠和过滤的表格，该怎么写？
我们的思路是，我们先写一个表格，最正常不过的表格。我们来看看我们的表格形式是什么样子的。然后给表格加一个搜索框。

```javascript
$(function () {
    // 添加点击事件，点击时候动态切换类名，并且让点击的父级下的子元素动态显示
    $(".parent").click(function () {
        $(this).toggleClass("select")
            // 这就是为什么类名是父级id构成的原因，方便操作，节省大量代码
            .siblings(".child-" + this.id).toggle()
        if ($(this).hasClass("select")) {
            $(this).find(".tips").html("点击展开")
        } else {
            $(this).find(".tips").html("点击收起")
        }
    })
    // 接下来过滤功能，过滤功能使用:contians
    $("#search").keyup(function () {
        var $val = $(this).val();
        if ($val == "") {
            $("tbody tr").show();
        } else {
            $("tbody tr").hide().filter(".child:contains(" + $val + ")").show();
        }
    })
})
```
