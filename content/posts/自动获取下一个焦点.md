> **一、自动获取焦点的demo的几种写法**

很多时候，我们会发现，在我们填写一个表单的过程中，每当我们填写完一个文本框之后，下一个文本框会自动获取焦点，尤其是在邮编，完整的座机电话号填写的过程中。这样可以节省用户的时间，给用户一个良好的体验。
> 1.事件绑定方式的写法

我们先看一下，我们的HTML结构，其实很简单，就是三个input文本框，每当输入的字符达到最大的length的时候，我们就让下一个input自动获取到焦点。代码如下：
```html
<form id="myform">
    <input type="text" name="" value="" style="width:80px;height:60px;font-size:18px;" maxlength="2" id="textbox1">
    <input type="text" name="" value="" style="width:80px;height:60px;font-size:18px;" maxlength="3" id="textbox2">
    <input type="text" name="" value="" style="width:80px;height:60px;font-size:18px;" maxlength="4" id="textbox3">
</form>
```
我们再来看一下，js代码；
```javascript
// 常规的写法，使用for循环时候注意事项，i的变量引用问题，由于引用i的时候，i会返回最终储存的值，需要使用闭包强制改变i的引用；
var form = document.getElementById('myform');
for (var i = 0, len = form.elements.length; i < len; i++) {
    form.elements[i].onkeyup = function (i) {
        return function () {
            if (this.value.length == this.maxLength) {
                if (form.elements[i + 1]) {
                    form.elements[i + 1].focus();
                } else {
                    return;
                }
            }
        }
    }(i);
}
```

> 2.ES6方式写法

在第一种写法的基础上，我们发现，如果我们不使用闭包，那么i的引用就会取到最后一个值，这让人很恼火，那么有没有更快捷的方式去避免这种情况，我们可以使用ES6的let来定义i，这样就定义了一个块级作用域；

```javascript
var form = document.getElementById('myform'),
    elements = form.elements;
for (let i = 0, len = elements.length; i < len; i++) {
    elements[i].onkeyup = function (event) {
        if (this.value.length == this.maxLength) {
            if (elements[i + 1]) {
                elements[i + 1].focus();
            } else {
                return;
            }
        }
    }
}
```

> 3.事件监听器的写法

这种写法的优点，在于可以在一个元素上绑定多个事件并且没有冲突；
```javascript
// 封装一个获取id的函数，代码太多懒得一一去写
        function $(id) {
            return document.getElementById(id);
        }
// 将绑定的事件独立出来
        function tabForward(event) {
            var target = event.target;
            if (target.value.length == target.maxLength) {
                var form = target.form;
                for (var i = 0, len = form.elements.length; i < len; i++) {
                    if (form.elements[i] == target) {
                        if (form.elements[i + 1]) {
                            form.elements[i + 1].focus();
                        }
                        return;
                    }
                }
            }
        }
        var oTxt1 = $('textbox1'),
            oTxt2 = $('textbox2'),
            oTxt3 = $('textbox3');
// 绑定事件，大功告成。
        oTxt1.addEventListener('keyup', tabForward, false);
        oTxt2.addEventListener('keyup', tabForward, false);
        oTxt3.addEventListener('keyup', tabForward, false);
```
> 4.jquery的写法

个人觉得jquery是最全面的框架，没有之一，但就是需要频繁的操作DOM
```javascript
        $('form input').on('keyup',function (event) {
            if ($(this).val().length == $(this).attr('maxlength')) {
                if ($(this).next()) {
                    $(this).next().focus();
                }else {
                    return;
                }
            }
        })
```
