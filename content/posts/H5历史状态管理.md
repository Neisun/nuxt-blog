> **一、首先了解一下history对象**

window.history 表示window对象的历史记录，是由用户主动产生，并且接受javascript脚本控制的全局对象。window对象通过 history 对象提供对览器历史记录的访问能力。它暴露了一些非常有用的方法和属性，让你在历史记录中自由前进和后退。

> **1.历史记录****的前进和后退**

我们在浏览器中是点击前进和后退的按钮，而在js中我们可以如下控制。

```javascript
window.history.back();
window.history.forward();
```

> **2.移动到指定的位置**

```javascript
window.history.go(n);
// n可以是负数或者正数，当然是整数，历史记录不可能是浮点数
```

> **3.想知道历史记录中到底有几条**

```javascript
window.history.length;
```

> **二、H5的历史状态管理**

随着AJAX技术的出现，极大的提高了页面的数据交互能力，但是随之出现的问题也是显而易见的。因为不能使用页面的后退按钮了。

为了解决这个问题，H5提出了历史状态管理这个概念。并且提出了相对简单易行的API接口。

1.  window.history.pushState({}," "," ");
2.  window.history.popState(event);
3.  window.history.replaceState({}," "," ");
我们一一说明，这三个接口。

<span style="color: #3366ff;">window.history.pushState({},' ','  ');</span>
<span style="color: #ff6600;">第一个参数</span>：表示传入当前页面的状态的数据；
<span style="color: #ff6600;">第二个参数</span>：是一个title，但是目前没有浏览器实现第二个参数，可以忽略不计，直接写上空的字符串，" "；
<span style="color: #ff6600;">第三个参数</span>：这个参数写了之后，url会发生变化，但不会向服务器发送请求；

<span style="color: #3366ff;">window.history.popState(event);</span>
当我们从状态栈中的一个状态跳到另一个状态popstate事件就会触发
（浏览器前后翻页触发，刷新页面不触发）
也就是说，他是负责监听状态改变的函数；
它的事件对象中有一个state属性存储着当初传递给pushState()的状态对象；

<span style="color: #3366ff;">window.history.replaceState({},"","");</span>
在参数方面和window.history.pushState({},"","")那是如出一辙的，这里不啰嗦，不做赘述；

> **接下来，我们用这三个API实现一个小小的DEMO**

先说一下，demo的需求。我们有一个按钮，点击会增加页码，同时有一个span用来显示当前的页数，同时改变url的状态，当我们点击浏览器的后退按钮时候，当前的页数也会相应的更新。额外的还有一个按钮，用来把当前页面标记为已读。貌似说的有点啰嗦，我们使用一个gif图来清晰的展示一下，然后在分析需求。

![](http://hunaisong.cn/wp-content/uploads/2017/07/history.gif)

因为代码中加入了完整的思路和注释，这里直接将代码贴出。

> HTML部分

```html
<button type="button" id="next">下一页</button>
<button type="button" id="read">标记为已读</button> 当前页数：
<span id="current_page">0</span>
```

> js部分

```javascript
<script>
// 封装一个获取id小函数
function $(id) {
    return document.getElementById(id);
}
// 获取需要的节点
var next = $('next'),
    curr = $('current_page'),
    read = $('read');
// 初始化页数
var page = 0;
// 点击下一页，页数增加，同时url也会变化，但不会刷新页面，仅仅只是改变状态
next.onclick = function (e) {
    page++;
    // 我们把每次页数增加都存入到状态对象
    window.history.pushState({page: page}, '', '?page=' + page);
    // 在完成这步之后，我们发现一个现象，就是点击下一页，页数增加，同时url也会发生相应的变化，而且不会刷新数据，特别像路由的写法

    // 显示当前页面的页数
    curr.innerHTML = page;
}
// 接下来，我们的想法是当点击浏览器的前进后退按钮，页码也会跟着变化
// 就需要使用popstate函数，这个函数是状态发生变化的时候触发
window.onpopstate = function (e) {
    // console.log(e),打印出e发现是一个popstateevent，里面的信息还是非常有用的；
    if (e.state) {
        curr.innerHTML = e.state.page;
        page = e.state.page;
    } else {
        curr.innerHTML = 0;
        page = 0;
    }
}
// 标记为已读
read.onclick = function (e) {
    // replacestate用于更新状态的
    // 他并不会向history中添加新的状态和记录
    // 而是更新当前的状态
    window.history.replaceState({page: history.state.page + '（已读）'}, '');
}
</script>
```
