> 什么是面向对象

各种面试时候，你会发现面试需求中写着，熟悉面向对象编程。那么什么是面向对象编程？为什么他这么重要？
在其他编程语言中，是有类的概念，通过类，我们可以创建无数个具有相同属性和方法的对象，但是在JavaScript中，没有类的概念。这就需要用一些别的手段和方式，创建出我们需要的这一类型的对象。
所以，下个定义吧，面向对象是一种相对的概念。不同于面向过程编程，主要注重的是结果，然后把这个过程抽象出来，这一种思维方式叫做面向对象。
为什么那么重要，因为在复杂的程序设计中，利用这种方式可以将代码耦合度降低，方便维护，方便修改。

> 创建对象

创建一个对象的方式有直接new Object()，或者字面量的形式。但是，如果想大量创建同样的对象，上边的两种方式能把你累死的。所以，我们才需要一些方式，创建相同类型的对象。

**1.工厂模式**

工厂模式是在函数中创建一个对象，增强对象，然后return这个对象
```javascript
function createPerson(name,age,job) {
    var obj = new Object();
    obj.name = name;
    obj.age = age;
    obj.job = job;
    obj.fn = function () {
        console.log(this.name)
    }
    return obj;
}
var person1 = createPerson('贝克汉姆','28','足球运动员');
var person2 = createPerson('詹姆斯','28','篮球运动员');
console.log(person1);
console.log(person2);
// 开发人员最开始想出来的方法，但是，无法查明对象类别
```
**2.构造函数模式**

看看构造函数创建对象的方式
```javascript
// 构造函数模式
function Person(name,age,job) {
    this.name = name;
    this.age = age;
    this.job = job;
    this.sayName = function () {
        console.log(this.name)
    }
}
var person3 = new Person('库里','24','篮球运动员');
var person4 = new Person('纳达尔','30','网球运动员');
// 构造函数模式与工厂模式之间的区别
// 1.构造函数并没有显式的创建一个对象
// 2.直接将属性和方法赋值给this
// 3.没有return语句
// 4.调用的时候使用new 操作符
// 你可能会问为什么使用new操作符
// 那么，就需要了解一下，在使用new操作符过程都发生了什么
// 1.创建一个对象
// 2.将属性和方法赋给this，所以this就指向了这个对象
// 3.执行构造函数中的代码，为新对象添加属性
// 4.返回新对象
// 所以使用new操作符的时候，都在执行上述四个步骤，返回一个新对象
// 存在缺点，就是构造函数中的方法在每个实例中都需要被创建一次，这很没有必要
console.log(person3.sayName == person4.sayName) // false
```
**3.原型模式**

构造函数模式是将属性和方法赋给this，而原型模式直接写在原型对象中。
```javascript
// 原型模式
function People() {

}
People.prototype.name = 'Neisun';
People.prototype.age = '26';
People.prototype.job = 'FE';
People.prototype.friends = ['David','John']
People.prototype.sayName = function () {
    console.log(this.name);
}
var person5 = new People();
var person6 = new People();
person5.sayName();
person5.friends.push('Leo');
console.log(person5.friends); // ['David','John','Leo']
console.log(person6.friends); // ['David','John','Leo'] 引用数据类型会出现问题
```
缺点，在操作实例的引用数据类型的时候会出现问题。

**4.构造函数+原型方式**

这种方式其实算是比较完美的
利用构造函数放置私有的属性和方法，原型放置公有的属性和方法；
```javascript
// 混合方式
function Person(name,age,job) {
    this.name = name;
    this.age = age;
    this.job = job;
    this.friends = ['David','John']
}
Person.prototype = {
    constructor:Person,
    sayName : function () {
        console.log(this.name);
    }
}
var person7 = new Person('Neisun',20,'Fe');
var person8 = new Person('Leo',22,'Back end');
person7.friends.push('Backham');
console.log(person7.friends); // ['David','John','Backham']
console.log(person8.friends); // ['David','John']
console.log(person7.sayName == person8.sayName) // true,说明二者是相同的函数，不是Function的不同实例
```
这种方式基本上算是绝佳的方式了，也是使用最多的方式。

还有寄生构造函数模式，稳妥构造函数模式，动态原型模式。
这三种模式，在开发过程中用的很少，而且这个概念和构造的方式，我不是特别理解，不敢苟同。
