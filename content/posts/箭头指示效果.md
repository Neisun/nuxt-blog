现在的页面设计偏向于酷炫效果和用户交互方面，今天在segmantfault上看到一个问题，蛮有趣的。就拿过来写一下。

![](http://www.hunaisong.cn/wp-content/uploads/2017/09/arrow.png)

上图的效果，用css动画写。
港真，起初思路不是用动画写，想的是定位方式去写，但定位的方式控制不好渐变色那部分，而且很麻烦。
实现思路：
箭头用文字<替代，
然后给容器元素背景颜色，
背景颜色是渐变色，
并且只填充到文字上，
背景大小为（`background-size`）宽度200%，为什么这么做？背景图片位置一半（50%）的时候正是需要的过渡颜色（两种颜色的交集）
通过动画控制`background-position`位置

看代码
```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>箭头效果</title>
    <style>
        p {
            color: #fff;
            margin: 50px auto;
            width: 500px;
            line-height: 80px;
            text-align: center;
            font-size: 80px;
            font-weight: bold;
            animation: move 1s infinite alternate;
            /* 核心部分，设置两倍的宽度，取中间的过渡颜色 */
            background-size: 200% 100%;
            /* 核心部分，渐变色设置 */
            background-image: -webkit-linear-gradient(left, red, blue);
            /* 核心部分，设置文字填充颜色 */
            -webkit-text-fill-color: transparent;
            /* 核心部分，设置背景填充部分，这里选择填充文字部分 */
            -webkit-background-clip: text;
        }

        @keyframes move {
            from {
                background-position: 50% 0;
            }
            to {
                background-position: 100% 0;
            }
        }
    </style>
</head>

<body>

>>>>>

</body>

</html>
```
