# 一个小笔记

记录一些常见的问题，使人困惑不解或者常常迷糊的问题和知识。

## x++与++x

这个东西不难，但容易让人搞迷糊。我想了一个办法去解决这种困惑，就是通过控制台打印；

```js
var x = 1;
console.log(++x,x) // 2,2;
console.log(x++,x) // 1,2;
// 很明显了，x怎么都会做加法运算被赋值，但是++x与x++就仿佛一个函数，返回的值不一样。
```

## 关于this的一道题

```js
var num = 100;
var obj = {
    num:200,
    inner:{
        num:300,
        print:function(){
            console.log(this.num)
        }
    }
};
var fn = obj.inner.print;
fn();
obj.inner.print();
(obj.inner.print)();
(obj.inner.print = obj.inner.print)();
```
解析一下上述的问题，关于this的指向，通常来说指向调用者（箭头函数例外，指向创建时候所处的对象）。

```js
// 答案如下
100
300
300
100
// fn() fn是定义的全局对象，所以fn()可以看成是window.fn()，所以答案是100
// obj.inner.print() 毋庸置疑，指向最近的调用者
// (obj.inner.print)() 也是直接执行了 obj.inner.print没啥好说的
// 重头戏在于，obj.inner.print = obj.innner.print，然后加上立即执行函数。
// 分两部分，第一部分，obj.inner.print = obj.inner.print 是个赋值表达式，赋值表达式是有返回值的。等于赋的值。
// 也就是那个函数
function(){
    console.log(this.num)
}
// 加上自执行函数
(function(){
    console.log(this.num)
})()
就是在全局环境下执行的函数，所以答案自然就是100
```
总结一下，挺有意思的一道题，考察了this，赋值表达式返回值的问题，以及立即执行函数。
