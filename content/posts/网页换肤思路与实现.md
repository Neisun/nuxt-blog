> **用户自定义是一种趋势**

无论开发人员承不承认，现在用户自定义已然成为了趋势。这样给了用户最佳的体验，而前端开发人员是最贴近用户的开发人员。这个职业的开发人员不仅仅需要考虑到代码，还需要考虑到用户交互和体验。换句话说，我们是用户的好朋友。而其中，属换肤最为常见。换肤其实就是换了一套样式。

> **具体实现思路**

样式我觉得，不用说多太多。随便定义几个颜色，点击的时候，切换一个背景色也就行了，最最关键的是，你要如何保证用自定义了颜色之后，刷新浏览器还是会保留用户的自定义颜色呢？
其实，已经说漏了。那就是保留，保留用户的信息，你会想到什么？我第一个想到的是cookie，那是保存用户信息的不二选择。还会想到什么？storage，这也是可以用来保存信息的。
那么实现的思路有了。我们在看看代码。
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <!--看出端倪了么，skin0.css是不是和第一个li的id对应着，其实一个id就是对应着一个css文件用来切换-->
    <link rel="stylesheet" type="" href="../css/less_css/skin0.css" id="cssfile"> 
    <script src="../js/lib/jquery-3.2.1.min.js"></script>
    <title>网页换肤</title>
</head>
<body>
<div class="container">
    <ul id="skin" class="clearfix">
        <li id="skin0" class="skin-item blue active" title="蓝色"></li>
        <li id="skin1" class="skin-item purple" title="紫色"></li>
        <li id="skin2" class="skin-item red" title="红色"></li>
    </ul>
</div>
```

```javascript
$(function () {
    // 每个li点击事件
    $(".skin-item").click(function () {
        changeSkin(this.id);
    })
    // 获取skinId
    var skinId = localStorage.getItem("skin");
    // 判断当前是否存在id，如果存在那么就直接调用相对应的css文件 
    if (skinId) {
        changeSkin(skinId);
    }
   // 考虑到代码的复用性，封装一个函数，传入的形参就是id
    function changeSkin(id) {
        // 当前点击的元素添加激活样式，也就是小√；
        $("#"+id).addClass("active")
        .siblings().removeClass("active");
        // 通过id来动态加载css文件
        $("#cssfile").attr("href","../css/less_css/"+id+".css");
        // 换肤的精髓之处在于，是要存到cookie中或者storage中，存当前的id
        localStorage.setItem("skin",id);
    }
})
```
至此一个最简易的网页换肤就完成了。思路其实是最重要的，重在思考问题的角度和方式。同样的，有了思路之后，还需要有一个完美的布局。一个好的布局同样会减少你的代码量和难度。
