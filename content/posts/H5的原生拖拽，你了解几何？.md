> **H5拖拽的起源**

正所谓所有的事物都会有一个起源的过程，H5的拖拽同样不例外。H5之所以把它纳入规范，我们还是需要感谢一下万恶的IE。虽然他很多时候非常讨厌，让我们工作量增加许多（每次都需要写大量的代码做兼容），但是它也做出了卓越的贡献，我们今天要说的这个H5拖拽就是其中之一。

> **要拖拽一个元素，我们需要怎么做？**

如果要拖拽一个元素，我们需要给这个元素加上一个属性draggable="true"，任何元素只要加上这个属性就可以实现拖拽。之前的老版本浏览器只允许两种对象进行拖拽，图像和文本。

示例代码：
```html
<!--被拖拽的元素-->
<div id="dragElement" style="width: 80px; height: 80px; background: blue; color: #fff;" draggable="true">被拖拽的元素</div>
<!--放置的目标-->
```
> **把元素拖拽到目标**

既然，元素已经可以拖拽了，那么总得有一个拖拽的目标不是？难道漫无目的地在雨夜前行？（一下子又文艺了。。）；

放置目标有三个事件，dragenter，dragover，drag事件。而且我们会发现，在把元素拖拽起来到这个目标元素上的时候，人家是拒绝的。为什么？因为浏览器默认行为是阻止。

所以我们需要在其中的enter和over事件上阻止默认行为。
示例代码：
```javascript
// 先获取节点
var dragE = document.getElementById('dragElement');
var dragT = document.getElementById('dragTarget');
//  给目标元素加上阻止默认行为事件，注意此处没处理兼容性问题。
dragT.ondragenter = function (event) {
    event.preventDefault();
    event.dropEffect = "move";
    console.log('进入目标元素');
}
dragT.ondragover = function (event) {
    event.preventDefault();
    console.log('在移动中')
}
```
这基本上就可以愉快的拖动了，但是要想把这个元素拖到目标元素中，是需要把它添加到目标元素的节点中。dragT.appendChild(dragE);

> 我们来看看完整的代码是该怎么去实现的

HTML部分
```html    
<!--被拖拽的元素-->
<div id="dragElement" style="width: 80px; height: 80px; background: blue; color: #fff;" draggable="true">被拖拽的元素</div>
<!--目标元素-->
```
js部分
```javascript       
// 先获取节点
var dragE = document.getElementById('dragElement');
var dragT = document.getElementById('dragTarget');
// 开始拖拽
dragE.ondragstart = function (event) {
    // 这个属性表示允许拖拽元素的哪种dropEffect，而且必须在dropstart事件中设置
    event.effectAllowed = 'move';
    console.log('开始拖拽了哦');
    // 可以设置传递的信息
    event.dataTransfer.setData('text','拖拽信息');
}
// 拖拽中
dragE.ondrag = function (event) {
    console.log('拖拽中')
}
// 拖拽结束
dragE.ondragend = function (event) {
    console.log('拖拽结束')
}
// 进入到目标元素
dragT.ondragenter = function (event) {
    event.preventDefault();
    event.dropEffect = "move";
    console.log('进入目标元素');
}
// 在目标元素中晃悠。。
dragT.ondragover = function (event) {
    event.preventDefault();
    console.log('在移动中')
}
// 放置
dragT.ondrop = function (event) {
    //  获取设置的信息
    var text =event.dataTransfer.getData('text');
    console.log('元素被放置'+'元素信息是：'+text);
    //  插入到目标元素中
    dragT.appendChild(dragE);
}
```
